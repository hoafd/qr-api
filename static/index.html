📖 Tài liệu API

Hướng Dẫn Sử Dụng API

Base URL: http://<server-ip>:<port>

🔐 Xác Thực API Key (nếu được bật)

Khi tính năng API Key được bật trong QR API Server Desktop App, tất cả các request đến /api/* phải kèm theo header hoặc query param sau: 

# Header (khuyến nghị):
X-API-Key: AbCd1234XyZw

# Hoặc query param (cho GET):
GET /api/generate-qr?data=...&api_key=AbCd1234XyZw

⚠ Lấy mã API Key trong Desktop App → Phần Bảo mật API Key. Nếu sai, server trả về HTTP 401.

POST /api/scan-qr — Quét mã QR từ ảnh CCCD

Request

  • 📎 Content-Type: multipart/form-data
  • 🖼 file: Ảnh JPG / PNG / WEBP (≤ 10MB)
  • 🔑 X-API-Key: (nếu bật bảo mật)

Engine Decode

  • 1️⃣ WeChat QR AI (Caffe model)
  • 2️⃣ OpenCV QRCodeDetector
  • 3️⃣ pyzbar (fallback)

Response — CCCD thành công

{
  "success": true,
  "cccd":      "012345678901",
  "full_name": "NGUYEN VAN A",
  "dob":       "01/01/1990",
  "gender":    "Nam",
  "address":   "Số 1, Phố X, Phường Y, Q.Z, TP.HCM",
  "raw_data":  "012345678901|...",
  "method":    "wechat_ai/original"
}

Ví dụ code

cURL

curl -X POST http://server:8000/api/scan-qr \
  -H "X-API-Key: AbCd1234XyZw" \
  -F "file=@cccd.jpg"

Python

import requests
r = requests.post(
  "http://server:8000/api/scan-qr",
  headers={"X-API-Key": "AbCd1234XyZw"},
  files={"file": open("cccd.jpg","rb")}
)
print(r.json())
GET /api/generate-qr — Tạo mã QR, trả về PNG

Query Parameters

Tham số Kiểu Mặc định Mô tả
datastring—Nội dung mã QR (bắt buộc, ≤ 2000 ký tự)
sizeint256Kích thước ảnh px (64 – 1024)
error_correctionstringMMức sửa lỗi: L (7%) / M (15%) / Q (25%) / H (30%)
fgstring#000000Màu QR (hex, URL-encoded)
bgstring#ffffffMàu nền (hex, URL-encoded)

cURL — tải PNG

curl -o qr.png \
  "http://server:8000/api/generate-qr\
?data=https%3A%2F%2Fexample.com\
&size=512&error_correction=H"

JavaScript

const res = await fetch(
  `/api/generate-qr?data=${encodeURIComponent(text)}&size=512`,
  { headers: { "X-API-Key": key } }
);
const blob = await res.blob();
// blob →  hoặc download

📋 Mã Lỗi HTTP

Mã Ý nghĩa
200Thành công
400File quá lớn (>10MB) hoặc định dạng không hỗ trợ
401Thiếu hoặc sai API Key (X-API-Key)
422Không nhận diện được mã QR trong ảnh
429Rate limit: Scan 30 req/phút, Generate 60 req/phút
503QR Engine chưa sẵn sàng
